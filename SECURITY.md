# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in this repository, please do not open a public Issue or disclose sensitive details publicly.

Report the issue privately to the repository maintainer through the GitHub security reporting channel or another private channel available to the maintainer. Include a concise description, the affected file or component, steps to reproduce when safe, and the potential impact. Do not include passwords, tokens, private keys, personal data, identity documents, real case documents, or confidential attachments.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before making technical details public. Do not attempt to access, modify, or disclose data that does not belong to you.

## Scope and limitations

This repository contains public documentation and software-related materials. It is not a legal service, does not provide legal advice, and does not authorize access to private repositories or confidential case materials.

Security reports are handled according to the information available to the maintainer. The existence of this policy does not guarantee a response time or a particular remediation outcome.

## Privacy

If you accidentally disclose personal data or a secret, stop sharing it publicly and notify the maintainer privately so that the exposure can be assessed and remediated.
