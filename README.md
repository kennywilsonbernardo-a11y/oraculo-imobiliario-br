# Oraculo Imobiliario BR
O primeiro motor de due diligence imobiliaria 100% automatizado do Brasil.

## O que faz
Digite a matricula e receba em 3 minutos um dossie juridico, fiscal e tributario completo.

Robos: ONR/SREI, ARISP, CNIB, TJAL, Prefeitura, Receita Federal.
IA: Claude API para ler matricula e gerar Score de Risco.
